# Brain-Atlas
![Brain Atlas — Asistente Personal Inteligente para el Bienestar](https://github.com/lazarolpro/Brain-Atlas/blob/main/Interfaz%20del%20prototipo%20local%20Brain%20Atlas%20en%20desarrollo.png)

**Brain Atlas** es el cerebro digital que es el núcleo detrás de un proyecto experimental de desarrollo propio orientado a crear un asistente personal inteligente que facilite la organización del conocimiento, el seguimiento de hábitos y el acompañamiento cotidiano hacia un estilo de vida más saludable "Control-Health-Care".

Desarrollado con Python, en el framework Opencode, usando un modelo de IA local y Streamlit como frontend y fastAPI como backend, el proyecto integra una interfaz visual interactiva para explorar información, relacionar conocimientos y organizar recursos personales desde un entorno local.

Su enfoque combina tecnología, gestión del conocimiento e inteligencia artificial aplicada con el objetivo de convertir información dispersa en una experiencia personal más organizada, accesible y útil para la toma de decisiones cotidianas.

### Objetivos del proyecto

- **Contribuir al Bienestar personal diario:** apoyar la organización y el seguimiento de hábitos relacionados con un estilo de vida saludable.
- **Gestión del conocimiento:** estructurar y explorar información mediante representaciones visuales interactivas.
- **Asistencia inteligente:** experimentar con herramientas de IA orientadas a facilitar el acceso al conocimiento personal.
- **Privacidad y autonomía:** priorizar un entorno de ejecución local y mantener el control sobre los recursos del proyecto.
- **Innovación aplicada:** explorar la integración de desarrollo de software, visualización de datos y asistencia digital en una herramienta de uso personal.

### Tecnologías y áreas de desarrollo

- Python
- Streamlit
- FastAPI
- Opencode
- Interfaces interactivas y visualización de información
- Gestión y organización del conocimiento
- Inteligencia artificial aplicada
